# 🎓 思い出の覗き込み 3D フォト＆ビデオステージ（ステレオサウンド＆Googleドライブ連携版）

Webカメラによる顔追跡（オフアクシス投影）やマウス操作で、立体的なネオントンネル空間の中を奥へ進みながら写真や動画を「覗き込む」ように鑑賞できるインタラクティブWebアプリケーションです。

---

## 📋 1. 現在の主な仕様・機能一覧

### ① 3D空間・ビジュアル演出
* **オフアクシス・カメラワーク（立体覗き込み効果）**:
  * **顔追跡モード**: MediaPipe FaceMeshを使用し、Webカメラでユーザーの顔（鼻根部）のX・Y座標および両目の距離（Z軸：奥行き）をリアルタイムに検出。画面を「窓」に見立てて視点を動かすことで、奥行きのある3D空間を横や上下から覗き込む体験ができます。
  * **マウス操作モード**: カメラを起動していない状態でも、マウスカーソルの動きに合わせて視点が連動します。
* **AIによる人物自動切り抜き**:
  * MediaPipe SelfieSegmentationを搭載。背景付きの写真を読み込んだ際、人物部分を自動で認識して背景を透過処理し、3D空間内に立体的に配置します（すでに透過済みのPNG画像等はそのまま配置されます）。
* **マルチアスペクト比最適化**:
  * PCの横画面（16:9）、スマホの縦画面（9:16）、正方形など、ウィンドウの縦横比に合わせてトンネルの幅・高さ・アセットの配置範囲を自動調整します。

### ② メディア読み込み＆ステレオサウンド
* **ローカルファイル読み込み**:
  * ドラッグ＆ドロップ、またはファイル選択ダイアログから複数枚の画像（JPEG/PNG/WebP等）および動画（MP4/WebM/OGG）を一括で追加できます。
* **Googleドライブ連携（GUI完結型）**:
  * Google Apps Script（GAS）を経由し、指定したGoogleドライブのフォルダ内にある画像・動画を一括取得します。
  * フォルダの共有URLをそのまま貼り付けても、自動でフォルダIDを抽出します。
  * 入力したGASのURLやフォルダURLはブラウザ（`localStorage`）に自動保存されます。
  * URLパラメータ（`?gas=GASのURL&folder=フォルダID`）を付与することで、設定済みの状態で他者へリンク共有が可能です。
* **空間ステレオオーディオ（Web Audio API）**:
  * 動画アセットが空間内の「左」にあるときは左耳から、「右」にあるときは右耳から音が聞こえるよう、リアルタイムで左右のパンニング（定位）を制御します。

### ③ カスタマイズ＆書き出し機能
* **進行スピード調整**: スライダーでトンネル内を進む速度（`2.0` 〜 `30.0`）をリアルタイムに変更可能。
* **背景変更**: 空間の最奥にある背景壁を任意の画像に変更可能（アスペクト比を維持して中央トリミング）。
* **シームレス・ループ動画の自動書き出し**:
  * 現在の進行スピードに合わせ、トンネルのグリッド周期と完全に一致する長さ（約5秒間）のシームレスループ動画を自動録画し、MP4またはWebM形式でダウンロードできます。

## 🛠️ 2. セットアップ手順

このシステムは **「GitHub Pages（HTML本体）」** と **「Google Apps Script（ドライブ連携用API）」** の2つで構成されています。

### Step 1：Google Apps Script（GAS）の準備
Googleドライブ上のフォルダから画像・動画一覧を取得するための小さなプログラムを設定します。

1. [Google Apps Script](https://script.google.com/) にアクセスし、**「新しいプロジェクト」** を作成します。
2. エディタに最初から書かれているコードをすべて消し、用意した **`Code.js`** の内容を貼り付けて保存（`Ctrl + S` / `Cmd + S`）します。
3. 画面右上の **「デプロイ」＞「新しいデプロイ」** をクリックします。
4. 種類の選択（歯車アイコン）から **「ウェブアプリ」** を選択し、以下のように設定します。
   * **説明**: 任意（例：`3Dステージ連携API`）
   * **次のユーザーとして実行**: **自分**
   * **アクセスできるユーザー**: **全員**（※外部のGitHub Pagesからアクセスするために必須です）
5. **「デプロイ」** をクリックします（初回のみGoogleアカウントのアクセス承認画面が出るため、「詳細」＞「安全ではないページに移動」から許可してください）。
6. 完了画面に表示される **「ウェブアプリのURL」**（`https://script.google.com/macros/s/〜/exec`）をコピーして控えておきます。

---

### Step 2：Googleドライブ側のフォルダ準備
1. Googleドライブに写真や動画を入れる専用フォルダを作成し、メディアファイルをアップロードします。
2. フォルダを右クリック ＞ **「共有」＞「共有」** を開きます。
3. 「一般的なアクセス」を **「リンクを知っている全員（閲覧者）」** に変更します。
4. フォルダのリンク（`https://drive.google.com/drive/folders/〜`）をコピーします。

---

### Step 3：GitHub Pages への公開（HTML配置）
HTMLファイル自体はコードを書き換える必要はありません。そのまま公開できます。

1. GitHubで新しいリポジトリ（例：`3d-photo-stage`）を作成します。
2. **`photo-popup-3d-room-v18.html`** をリポジトリにアップロードし、ファイル名を **`index.html`** に変更します（そのままのファイル名でもアクセス可能ですが、`index.html` にするとURLが短くなります）。
3. リポジトリの **「Settings」＞「Pages」** を開きます。
4. 「Build and deployment」の **Branch** で `main`（または `master`）を選択し、**「Save」** をクリックします。
5. 数分待つと、ページ上部に公開URL（`https://ユーザー名.github.io/リポジトリ名/`）が表示されます。

## 🚀 3. アプリの使い方・共有方法

### 初回読み込み手順
1. 公開したGitHub PagesのURLをブラウザで開きます。
2. 左上の操作パネル内にある **「🌐 Googleドライブから一括読込」** の欄に以下を貼り付けます。
   * **上段**: Step 1でコピーした `GASのウェブアプリURL`
   * **下段**: Step 2でコピーした `GoogleドライブのフォルダURL`（またはフォルダID）
3. **「📁 ドライブから読み込む」** をクリックすると、AIによる人物切り抜き処理が行われ、3D空間に写真・動画が展開されます。
   * ※一度読み込むとURLはブラウザに自動保存され、次回以降はGASのURL入力欄が自動で折りたたまれます。

### 他の人にURLを共有する場合（ワンクリック起動）
他の人にこの3Dステージを見てもらう際、毎回URLをコピペしてもらう手間を省くには、以下のような形式でURLを作成して共有します。

```text
https://あなたのGitHubPagesのURL/?gas=【GASのウェブアプリURL】&folder=【GoogleドライブのフォルダID】
```

このURLを開くと、最初からGASのURLとフォルダIDが入力欄にセットされた状態で起動します。

## ⚠️ 4. プライバシーおよび運用上の注意事項

1. **公開範囲とプライバシーについて**
   * GitHub PagesにアップロードしたHTMLファイル自体は誰でも閲覧可能ですが、**HTMLの中に写真や動画のデータは含まれない**ため、GitHub側から写真が流出することはありません。
   * ただし、Googleドライブのフォルダは「リンクを知っている全員」に設定し、GASも「全員」に公開する仕組み上、**「GASのURL」と「フォルダID」の両方を知っている人はデータにアクセス可能**です。不特定多数に見られたくない場合は、共有URLの取り扱いにご注意ください。
2. **ファイルサイズ・動画読み込みの制限**
   * Googleドライブの仕様上、極端にファイルサイズが大きい動画や大量のファイル（100枚以上など）を一度に読み込もうとすると、ブラウザのメモリ不足やGoogle側のアクセス制限により読み込みが失敗することがあります。写真は1枚あたり数MB以下、動画は短めのクリップ（数十MB程度まで）に抑えることを推奨します。
3. **ブラウザの自動再生ポリシー**
   * Googleドライブから動画を読み込んだ際、ブラウザのセキュリティ制限により最初は音声がミュートされたり再生が止まったりすることがあります。その場合は画面内のどこかをクリックするか、「🔊 サウンド: ON/OFF」ボタンを押すことで音声が有効になります。
